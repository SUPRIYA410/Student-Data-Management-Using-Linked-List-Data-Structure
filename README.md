# Student-Data-Management-Using-Linked-List-Data-Structure
Student Data Management Using Linked List in c. This project manage student records such as roll number,name, and percentage. It supports adding, deleting, searching, displaying, and sorting student data, demonstrating dynamic memory allocation and linked list operations.# Student Record Management System

## 📌 Project Description

The **Student Record Management System** is a menu-driven C programming project developed using a **singly linked list**. It manages student records using dynamic memory allocation and provides operations such as adding, deleting, displaying, modifying, sorting, saving, and reversing student records.

## 🎯 Objective

The main objective of this project is to implement a Student Record Management System using:

- Singly Linked List
- Dynamic Memory Allocation
- Modular Programming
- Searching
- Sorting
- File Handling

## 🛠️ Technologies Used

- C Programming
- GCC Compiler
- Linux/Ubuntu
- Singly Linked List
- File Handling

- Student records are maintained using a singly linked list.
- Each new node is dynamically allocated.
- Source code is divided into separate modules.
- Records are saved in student.dat.
- Dynamically allocated memory is released before program termination.
- Invalid inputs and unavailable records are handled appropriately.
